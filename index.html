How to export from ChatGPT

  1. Go to chat.openai.com
  2. Click your profile icon (top right)
  3. Select Settings
  4. Click Data Controls
  5. Click Export under "Export Data"
  6. Click Confirm export
  7. Wait for email with download link
  8. Download and extract the ZIP file
  9. Upload conversations.json below

How to export from Claude

  1. Go to claude.ai
  2. Click your initials (bottom left)
  3. Select Settings
  4. Navigate to Account
  5. Click Export Data
  6. Wait for email with download link (may take up to 24 hours)
  7. Download and upload the JSON file below

Note: If export is not available, you can use browser extensions like "Claude Export Tool" to export conversations.

How to export from Microsoft Copilot

  1. Go to account.microsoft.com/privacy/download-your-data
  2. Sign in with your Microsoft account
  3. Select Bing & Cortana or Copilot from the data categories
  4. Click Create an archive
  5. Wait for the email notification (may take several hours)
  6. Download and extract the ZIP archive
  7. Find and upload the CopilotInteractions.json or similar JSON file below

Note: The export file name and structure may vary. Any JSON file from the Copilot section of the Microsoft privacy download is supported.
